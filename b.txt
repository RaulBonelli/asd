1. ESTRUTURA BÁSICA DO FLASK
==================================================

Criar uma aplicação:

```python
from flask import Flask

app = Flask(__name__)

app.secret_key = "chave-secreta"

@app.route("/")
def home():
    return "Hello World!"

if __name__ == "__main__":
    app.run(debug=True)
```

CONCEITOS:
- Flask: framework Python para aplicações web.
- @app.route(): define uma rota.
- def: define uma função.
- return: devolve uma resposta ao navegador.
- debug=True: ativa modo de depuração.

2. ROTAS E MÉTODOS HTTP
==================================================

GET: buscar informações.
POST: criar informações.
PUT: atualizar um registro.
PATCH: atualizar parcialmente.
DELETE: excluir informações.

Exemplo:

```python
@app.route("/usuarios", methods=["GET"])
def listar_usuarios():
    return "Lista de usuários"

@app.route("/usuarios", methods=["POST"])
def criar_usuario():
    return "Usuário criado"
```

Uma rota pode aceitar vários métodos:

```python
@app.route("/usuarios/<int:id>", methods=["GET", "DELETE"])
def usuario(id):
    return f"Usuário {id}"
```

<int:id> transforma o parâmetro em inteiro.

Outros conversores:
- <string:nome>
- <int:id>
- <float:valor>
- <path:caminho>

3. ORM — OBJECT RELATIONAL MAPPING
==================================================

ORM permite manipular bancos de dados utilizando classes e objetos Python em vez de escrever SQL manualmente.

Exemplo com Flask-SQLAlchemy:

```python
from flask_sqlalchemy import SQLAlchemy

app.config["SQLALCHEMY_DATABASE_URI"] = "sqlite:///banco.db"

db = SQLAlchemy(app)
```

CRIAR UMA TABELA:

```python
class Usuario(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    nome = db.Column(db.String(100), nullable=False)
    email = db.Column(db.String(120), unique=True)
```

CONCEITOS:
- db.Model: transforma a classe em uma tabela.
- db.Column: define uma coluna.
- db.Integer: tipo inteiro.
- db.String: texto.
- primary_key=True: chave primária.
- nullable=False: campo obrigatório.
- unique=True: impede valores duplicados.

CRIAR AS TABELAS:

```python
with app.app_context():
    db.create_all()
```

4. CRUD COM ORM
==================================================

CREATE — CRIAR:

```python
novo = Usuario(
    nome="João",
    email="joao@email.com"
)

db.session.add(novo)
db.session.commit()
```

READ — LER:

Buscar todos:

```python
usuarios = Usuario.query.all()
```

Buscar pelo ID:

```python
usuario = db.session.get(Usuario, id)
```

Buscar pelo primeiro resultado:

```python
usuario = Usuario.query.first()
```

Buscar por uma coluna:

```python
usuario = Usuario.query.filter_by(nome="João").first()
```

Buscar com condição:

```python
usuarios = Usuario.query.filter(
    Usuario.id > 5
).all()
```

UPDATE — ATUALIZAR:

```python
usuario = db.session.get(Usuario, id)

if usuario:
    usuario.nome = "Novo nome"
    db.session.commit()
```

DELETE — EXCLUIR:

```python
usuario = db.session.get(Usuario, id)

if usuario:
    db.session.delete(usuario)
    db.session.commit()
```

IMPORTANTE:
- add(): adiciona um objeto à sessão do banco.
- commit(): confirma as alterações no banco.
- delete(): marca um objeto para exclusão.
- all(): retorna todos os resultados.
- first(): retorna o primeiro resultado ou None.
- filter_by(): filtra por igualdade.
- filter(): permite condições mais complexas.

6. SESSÕES — SESSION
==================================================

HTTP não mantém automaticamente a identidade do usuário entre requisições.

Sessões permitem guardar informações associadas ao visitante.

IMPORTAR:

```python
from flask import session
```

CONFIGURAR:

```python
app.secret_key = "minha-chave-secreta"
```

SALVAR INFORMAÇÃO:

```python
session["usuario_id"] = 10
```

LER INFORMAÇÃO:

```python
id = session.get("usuario_id")
```

VERIFICAR SE EXISTE:

```python
if "usuario_id" in session:
    print("Usuário identificado")
```

REMOVER UMA INFORMAÇÃO:

```python
session.pop("usuario_id", None)
```

LIMPAR A SESSÃO:

```python
session.clear()
```

DIFERENÇA:
- session["chave"] = valor: salva.
- session.get("chave"): consulta.
- session.pop(): remove uma chave.
- session.clear(): remove todos os dados da sessão.

IMPORTANTE:
A sessão padrão do Flask utiliza um cookie assinado armazenado no navegador. Não é recomendável guardar senhas ou informações secretas nele.

7. AUTENTICAÇÃO — LOGIN E LOGOUT
==================================================

Autenticação verifica a identidade do usuário.

AUTENTICAÇÃO:
"Quem é você?"

AUTORIZAÇÃO:
"O que você pode fazer?"

EXEMPLO DE LOGIN:

```python
from flask import request, session, jsonify
from werkzeug.security import check_password_hash

@app.route("/login", methods=["POST"])
def login():

    dados = request.get_json()

    email = dados.get("email")
    senha = dados.get("senha")

    usuario = Usuario.query.filter_by(
        email=email
    ).first()

    if usuario and check_password_hash(
        usuario.senha, senha
    ):

        session["usuario_id"] = usuario.id

        return jsonify({
            "mensagem": "Login realizado"
        }), 200

    return jsonify({
        "erro": "Credenciais inválidas"
    }), 401
```

CRIAR HASH DE SENHA:

```python
from werkzeug.security import generate_password_hash

senha_hash = generate_password_hash("123456")
```

VERIFICAR SENHA:

```python
check_password_hash(senha_hash, "123456")
```

LOGOUT:

```python
@app.route("/logout")
def logout():

    session.pop("usuario_id", None)

    return jsonify({
        "mensagem": "Logout realizado"
    }), 200
```

PROTEGER UMA ROTA:

```python
@app.route("/perfil")
def perfil():

    if "usuario_id" not in session:
        return jsonify({
            "erro": "Não autenticado"
        }), 401

    return jsonify({
        "mensagem": "Acesso permitido"
    }), 200
```

FLUXO DE AUTENTICAÇÃO:

1. Usuário envia email e senha.
2. Flask recebe os dados.
3. Flask procura o usuário no banco.
4. Flask verifica a senha.
5. Se estiver correta, salva o ID na sessão.
6. Nas próximas requisições, Flask verifica a sessão.
7. Logout remove a identificação da sessão.

8. REQUISIÇÕES HTTP — REQUEST
==================================================

O objeto request permite acessar informações enviadas pelo cliente ao Flask.

IMPORTAR:

```python
from flask import request
```

RECEBER JSON:

```python
dados = request.get_json()
```

ACESSAR VALORES:

```python
nome = dados.get("nome")
idade = dados.get("idade")
```

RECEBER FORMULÁRIO:

```python
nome = request.form.get("nome")
```

RECEBER PARÂMETROS DA URL:

URL:
```text
/buscar?nome=Joao
```

Python:

```python
nome = request.args.get("nome")
```

DIFERENÇAS:

- request.get_json(): recebe JSON.
- request.form: recebe dados de formulários.
- request.args: recebe parâmetros da URL.
- request.method: informa o método HTTP.
- request.files: acessa arquivos enviados.

EXEMPLO:

```python
@app.route("/usuarios", methods=["POST"])
def criar_usuario():

    dados = request.get_json()

    nome = dados.get("nome")

    if not nome:
        return jsonify({
            "erro": "Nome obrigatório"
        }), 400

    return jsonify({
        "nome": nome
    }), 201
```

10. FETCH — REQUISIÇÕES ASSÍNCRONAS
==================================================

fetch() permite que JavaScript faça requisições HTTP sem precisar recarregar a página.

GET:

```javascript
async function buscarUsuarios() {

    const response = await fetch("/usuarios");

    const dados = await response.json();

    console.log(dados);
}
```

POST:

```javascript
async function criarUsuario() {

    const response = await fetch("/usuarios", {

        method: "POST",

        headers: {
            "Content-Type": "application/json"
        },

        body: JSON.stringify({
            nome: "João",
            email: "joao@email.com"
        })

    });

    const dados = await response.json();

    console.log(dados);
}
```

DELETE:

```javascript
async function excluirUsuario(id) {

    const response = await fetch(
        `/usuarios/${id}`,
        {
            method: "DELETE"
        }
    );

    const dados = await response.json();

    console.log(dados);
}
```

PUT:

```javascript
async function atualizarUsuario(id) {

    const response = await fetch(
        `/usuarios/${id}`,
        {
            method: "PUT",

            headers: {
                "Content-Type": "application/json"
            },

            body: JSON.stringify({
                nome: "Novo nome"
            })
        }
    );

    const dados = await response.json();

    console.log(dados);
}
```

CONCEITOS IMPORTANTES:

- fetch(): envia uma requisição.
- async: permite utilizar await dentro da função.
- await: espera a conclusão de uma Promise.
- response: resposta recebida do servidor.
- response.json(): converte o corpo JSON em objeto JavaScript.
- JSON.stringify(): transforma objeto JavaScript em texto JSON.
- headers: informa os metadados da requisição.
- body: contém os dados enviados.

IMPORTANTE:
Uma requisição assíncrona permite que outras tarefas do navegador continuem enquanto a resposta não chega.

VERIFICAR SE A RESPOSTA FOI BEM-SUCEDIDA:

```javascript
if (response.ok) {
    console.log("Sucesso!");
} else {
    console.log("Erro!");
}
```

response.ok é verdadeiro para códigos HTTP entre 200 e 299.

11. ROTAS DE API
==================================================

Uma API permite que aplicações se comuniquem por meio de requisições e respostas.

Uma API REST normalmente utiliza métodos HTTP para manipular recursos.

EXEMPLO DE API CRUD:

```python
from flask import request, jsonify

@app.route("/api/usuarios", methods=["GET"])
def listar():

    usuarios = Usuario.query.all()

    resultado = []

    for usuario in usuarios:
        resultado.append({
            "id": usuario.id,
            "nome": usuario.nome
        })

    return jsonify(resultado), 200
```

CRIAR:

```python
@app.route("/api/usuarios", methods=["POST"])
def criar():

    dados = request.get_json()

    if not dados or not dados.get("nome"):
        return jsonify({
            "erro": "Nome obrigatório"
        }), 400

    novo = Usuario(nome=dados["nome"])

    db.session.add(novo)
    db.session.commit()

    return jsonify({
        "mensagem": "Criado",
        "id": novo.id
    }), 201
```

ATUALIZAR:

```python
@app.route("/api/usuarios/<int:id>", methods=["PUT"])
def atualizar(id):

    usuario = db.session.get(Usuario, id)

    if not usuario:
        return jsonify({
            "erro": "Não encontrado"
        }), 404

    dados = request.get_json()

    usuario.nome = dados.get(
        "nome",
        usuario.nome
    )

    db.session.commit()

    return jsonify({
        "mensagem": "Atualizado"
    }), 200
```

EXCLUIR:

```python
@app.route("/api/usuarios/<int:id>", methods=["DELETE"])
def excluir(id):

    usuario = db.session.get(Usuario, id)

    if not usuario:
        return jsonify({
            "erro": "Não encontrado"
        }), 404

    db.session.delete(usuario)
    db.session.commit()

    return jsonify({
        "mensagem": "Excluído"
    }), 200
```

12. CÓDIGOS DE STATUS HTTP
==================================================

200 OK:
Requisição realizada com sucesso.

201 CREATED:
Um recurso foi criado com sucesso.

204 NO CONTENT:
Operação realizada sem conteúdo de resposta.

400 BAD REQUEST:
Dados enviados incorretamente ou inválidos.

401 UNAUTHORIZED:
Autenticação ausente ou inválida.

403 FORBIDDEN:
Usuário autenticado, mas sem permissão.

404 NOT FOUND:
Recurso ou rota não encontrado.

405 METHOD NOT ALLOWED:
Método HTTP não permitido naquela rota.

409 CONFLICT:
Conflito com o estado atual do recurso, como duplicidade.

500 INTERNAL SERVER ERROR:
Erro interno no servidor.

EXEMPLOS:

```python
return jsonify({"erro": "Dados inválidos"}), 400
```

```python
return jsonify({"mensagem": "Criado"}), 201
```

```python
return jsonify({"erro": "Não encontrado"}), 404
```

DIFERENÇA ENTRE 401 E 403:

401 = Não está autenticado.

403 = Está autenticado, mas não tem autorização.

14. ERROS COMUNS E SOLUÇÕES
==================================================

KeyError:
Tentativa de acessar uma chave inexistente em um dicionário.

SOLUÇÃO:
```python
nome = dados.get("nome")
```

TypeError:
Operação incompatível entre tipos de dados.

AttributeError:
Tentativa de acessar atributo ou método inexistente.

NameError:
Variável não definida.

ImportError:
Erro ao importar módulo ou objeto.

404:
Rota ou recurso não encontrado.

405:
Método HTTP incorreto para a rota.

500:
Erro interno no servidor. Verifique o terminal e o traceback.

SQLAlchemy:
- Não esquecer db.session.commit().
- Verificar se o registro existe antes de atualizar ou excluir.
- Utilizar first() ou get() para buscar um único registro.
- Verificar se os dados recebidos são válidos.

FETCH:
- Conferir se a URL está correta.
- Conferir o método HTTP.
- Conferir o Content-Type.
- Conferir se o Flask está retornando JSON.
- Verificar response.ok.
- Não esquecer await response.json().
